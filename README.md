# PWAFE · PL01

Primeiro projecto com React, TypeScript, Vite e Tailwind CSS v4: um cartão de perfil responsivo.

## Como correr

```
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.

## Estrutura

- `src/App.tsx`: objecto `Perfil` tipado, função `saudacao` e o cartão (só com classes do Tailwind).
- `src/index.css`: `@import "tailwindcss";`
- `vite.config.ts`: plugins `react()` e `tailwindcss()`.
